# SOC Labs

A collection of hands-on cybersecurity exercises, technical notes, and practical learning projects focused on security monitoring, threat detection, and incident response.

This repository documents my progress as I develop the technical knowledge and practical skills required for an entry-level SOC Analyst role.

## Areas of Learning

* Security monitoring and log analysis
* Threat detection and incident investigation
* Network security fundamentals
* Cyberattack analysis and defensive strategies
* Security frameworks and threat intelligence
* Incident response fundamentals
